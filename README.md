# 英語マスター（EigoMaster）

高校入学レベルから、旧帝大・医学部を含む難関大学の合格レベルまで、大学入試英語の**読み・書き**を体系的に鍛える macOS アプリです。

## 主な機能

| 分野 | 内容 |
|---|---|
| 英単語・熟語 | 7段階のレベル別語彙（各レベル200語以上）と熟語・イディオム（各レベル約50）。英→日カード／4択／日→英スペルの3形式で学習。単語・熟語の切り替え表示、派生語・語法・アクセントの注意つき |
| 文法・語法 | 単元ごとの解説と演習（選択・空所補充・整序・英訳） |
| 英文解釈・構文 | 文型判定から下線部和訳まで。採点ポイントを見ながら自己採点 |
| 英作文 | 和文英訳・自由英作文・要約。語数カウント、模範解答、採点ポイント、任意で **Claude による AI 添削** |
| 長文読解 | オリジナル英文（全訳・語注つき）。読解速度（wpm）の計測、内容一致・記述設問 |
| 基礎知識 | 発音・アクセント、会話表現、ディスコースマーカー、英作文の型 |
| 復習 | 間隔反復（SRS）で忘れかけた頃に自動出題。「今日の学習」「間違いノート」 |
| 記録 | 日別の解答数・正答率・学習時間、レベル別の定着度、読解速度の推移 |

リスニング・スピーキングは将来のアップデートで追加予定です（コンテンツ形式は音声データの参照 `media` に対応済み）。

## 常に最新の状態に保つ仕組み

- **コンテンツ更新**：単語・問題・入試情報は `Content/` 以下の JSON パックとして管理しています。このリポジトリの `main` に push されたパックを、アプリが起動時（1日1回）または「コンテンツ更新」ボタンでダウンロードします。アプリを再ビルドする必要はありません。SHA-256 で改ざん・破損を検出します。
- **アプリ更新**：GitHub Releases に新しいバージョンが公開されると、ホーム画面に通知が出ます。

## ビルド

Xcode（Swift 6 以降）が必要です。外部ライブラリは使っていません。ビルドキャッシュや中間ファイルはすべてリポジトリ内（`.build/`, `.cache/`）に置かれ、内蔵 SSD は使いません。

```bash
scripts/build_app.sh
```

`build/EigoMaster.app` ができます。`--zip` を付けると配布用 zip を `dist/` に作ります。

```bash
scripts/swiftpm.sh test
```

### データの保存先

進捗（`progress.json`）とダウンロードしたコンテンツは、設定 > データと更新 で指定したフォルダに保存されます（既定は `~/Library/Application Support/EigoMaster`）。環境変数 `EIGO_DATA_DIR` でも指定できます。

## コンテンツの追加・更新

[docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md) を参照してください。手順の概要：

1. `Content/packs/*.json` を編集し、そのパックの `revision` を 1 増やす
2. `.build/debug/eigo-tool validate Content` で検証する
3. `.build/debug/eigo-tool manifest Content` で `manifest.json` を更新する
4. commit して `main` に push する → 各アプリが自動で取得

## 収録コンテンツについて

収録している英文・例文・問題・解説はすべてこのプロジェクトのために作ったオリジナルです。市販教材や過去の入試問題の転載は含みません。
